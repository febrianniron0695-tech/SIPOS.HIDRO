# 💧 SI POS HIDRO (Sistem Informasi Pelaporan Stasiun Hidrologi)

Aplikasi berbasis web & Progressive Web App (PWA) yang dirancang untuk pengumpulan, verifikasi, dan monitoring data curah hujan serta kondisi fisik peralatan stasiun hidrologi di wilayah Pulau Timor, Pulau Sumba, dan Pulau Flores.

## 📌 Isi Paket Repositori
- `index.html`: Antarmuka utama aplikasi (Observer, Admin, & Verifikator) berbasis Fetch API.
- `manifest.json`: Konfigurasi instalasi PWA di HP.
- `sw.js`: Service Worker untuk manajemen cache dan versi PWA.
- `Kode.gs`: Script backend API Router untuk dipasang pada Google Apps Script Web App.
- `.nojekyll`: File konfigurasi bypass builder Jekyll GitHub Pages.
